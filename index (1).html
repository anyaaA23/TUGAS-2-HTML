Tentang Coding Club

Coding Club SMKN 1 Subang merupakan kegiatan untuk mempelajari pemrograman dan teknologi.

Coding Club membantu siswa mengembangkan keterampilan coding dan membuat proyek sederhana.

Apa yang Dipelajari

  • HTML
  • CSS
  • JavaScript
  • Pemrograman Web
  • Git dan GitHub

Alur Mengikuti Coding Club

  1. Mengisi formulir pendaftaran
  2. Mengikuti pertemuan pertama
  3. Belajar dasar pemrograman
  4. Membuat proyek sederhana
  5. Presentasi hasil proyek

Kegiatan Coding Club

Belajar HTML

Mempelajari dasar-dasar HTML untuk membuat halaman web.

Membuat Website

Membuat website sederhana menggunakan materi yang telah dipelajari.

Project Showcase

Menampilkan dan mempresentasikan hasil proyek yang telah dibuat.
